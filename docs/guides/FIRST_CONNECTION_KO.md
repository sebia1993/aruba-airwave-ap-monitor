# AirWave AP Monitor — 처음 연결하기

대상: v0.1.3-preview.7 Windows 현장 검증본

1. 기존 EXE와 동일한 Windows 실행 계정 및 Live 데이터 폴더에서 새 EXE를 시작합니다. 신규 Live 데이터이고 연결 설정이 없다면 안내가 자동으로 열립니다. 기존에 수집 성공한 환경은 안내를 거치지 않습니다.
2. 관리 → 연결 설정 → 처음 연결 안내에서 언제든 열고 닫을 수 있습니다.
3. 서버 주소 입력란에 평소 사용하는 https://IP:포트를 입력하고 프록시 연결 경로와 5분 등 수집 간격을 설정해 저장합니다. 저장된 서버 주소는 현재 데이터 폴더에서 바꿀 수 없습니다.
4. AirWave의 AP 목록 읽기 권한을 가진 계정과 비밀번호를 수집 PC에서 등록합니다. 자격 증명은 Windows DPAPI로 해당 실행 계정에서만 복호화합니다.
5. 안내에서 연결 진단 실행을 누릅니다. HTTPS와 로그인, AP 목록 응답을 읽습니다. 인증서 오류라면 인증서 체인 갱신이 우선이며, 지문을 허용하려면 관리 기록과 독립적으로 SHA-256을 대조해야 합니다. 자동 조회만으로 인증서를 승인하지 않습니다.
6. HTTP 403이면 자동 재로그인하지 않습니다. AirWave /ap_list.xml 읽기 권한 또는 프록시 거부 여부를 점검합니다.
7. 진단 성공 후 첫 AP 수집 실행을 누르고 수집 기록과 AP 현황에서 유효하게 저장된 회차를 확인합니다. 단순 HTTP 200 또는 수집 접수만으로 완료로 판단하지 않습니다.

## 사내 장비 검증 — 사용자가 직접

- 기존 Live 데이터 폴더의 설정, 지문, SQLite 이력, 사건 메모가 보존되는지 확인
- 신규 Live 데이터에서 IP·포트 → 계정 → 진단 → 첫 수집을 실제로 수행
- 인증서 변경/신뢰 체인 오류와 HTTP 403이 자동 승인·자동 재로그인을 유발하지 않는지 확인
- AP 수집 성공/부분 확인/실패를 구분해 표시하고 제외 AP 대수를 AirWave와 대조
- Windows 서비스/예약 작업과 재시작 시 저장 데이터와 수집이 유지되는지 확인

이 문서에는 실제 사내 주소, 계정, 인증서 지문, 장비 내역을 포함하지 않았습니다.
