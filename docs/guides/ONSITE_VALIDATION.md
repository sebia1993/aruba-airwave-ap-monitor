# 사내 운영 확인 기록

개발 테스트·GitHub Windows CI와 실제 사내 PC/장비 확인을 구분한다. 아래 항목은 현장에서 확인하기 전까지 **미확인**이다. 계정 암호·쿠키·토큰·원문 사내 XML을 공개 저장소나 외부 서비스에 올리지 않는다.

최신 개발 완료 범위·소스 버전·CI 결과는 [개발 진행 및 검증 기록](../DEVELOPMENT_STATUS.md)을 확인한다. 진행 중인 작업이나 다른 소스 버전의 성공 결과를 현재 반입본의 통과로 옮겨 적지 않는다. 설치·실행은 [Windows 안내](README_WINDOWS.md), 업데이트·복원은 [복구 안내](UPDATE_AND_RECOVERY.md)를 따른다.

## 확인 기록

조직의 내부 기록 위치에 다음을 남긴다. 이 양식은 실제 운영 자료를 외부로 제출하라는 요청이 아니다.

- 확인 날짜·담당자·PC의 Windows 버전/아키텍처·AD 정책 적용 여부
- ZIP 이름·SHA256·`VERSION.json`의 소스 버전·검증한 CI 링크
- 선택한 실행 방식·실제 수집 계정·설치 경로·별도 데이터 폴더·포트
- 확인 항목 ID, 선택 회차·범위, 기대값·실제값, 결과(통과/실패/미확인), 남은 조치
- 오류가 있으면 발생 단계·안전한 오류 범주·회차를 기록한다. 암호·세션 토큰이나 원문 응답을 기록할 필요는 없다.

## 최초 실행과 기준 대조

1. 반입본의 ZIP 해시·버전·포함 기능을 확인한다. 버전 폴더와 데이터 폴더를 분리하고 Demo/Live를 다른 경로로 둔다.
2. 사내 정책이 허용하는 방식으로 실제 수집 계정을 정한다. 대화형 첫 실행 예시는 패키지 루트의 `Start-Monitor.ps1`이며, 서비스·예약 작업으로 운영할 때는 해당 프로세스의 계정을 기준으로 등록한다.

```powershell
.\Start-Monitor.ps1 -Mode live -DataDirectory 'C:\ProgramData\AirWaveAPMonitor\live' -Port 8765
```

3. `http://127.0.0.1:8765`의 **연결 설정**에서 실행 계정, HTTPS 출처, 프록시 경로를 확인한다. 화면을 연 사용자와 수집 계정이 다를 수 있다. 진단 성공과 운영 수집 성공은 별개다.
4. **다운 AP 현황**과 **수집 기록**에서 확정 회차·범위·Up/Down/미확인·오류를 확인한다. AirWave에서 동일한 권한·필터·대상 범위의 자료와 대조한다. 전체 실패·0건을 정상 0대로 해석하지 않는다.
5. 브라우저를 닫아도 프로세스가 계속 수집하는지 확인한다. 선택한 서비스 또는 예약 작업으로 운영할 때는 로그아웃·재부팅 후 계정·회차·열린 사건·설정이 유지되는지도 별도로 확인한다.

권한·계정·인증서·프록시·자동 시작 설정을 조직 승인 없이 우회하거나 전역 변경하지 않는다. 실제 장애 유발·전원 차단·시간 변경 시험은 운영 자료에서 수행하지 않는다. 필요한 실패 경계는 먼저 Demo·fixture·격리 데이터의 개발 검증 근거로 확인한다.

## 운영 기록·부가 관측 확인 순서

**운영 기록·대장**은 승인된 작은 대상부터 확인한다. 수동 등록·지점 배치·작업 정정은 자동 관측과 분리되어야 하며, 현재 변경 뒤에도 과거 회차·사건 스냅샷·CSV가 유지돼야 한다. CSV는 미리보기만으로 저장되지 않아야 한다. 여러 식별자가 다르거나 중복 행이 있으면 그 행을 적용하지 않는다. 미리보기 뒤 다른 창의 수정·장비 교체·DB 복원이 있었다면 다시 미리보기부터 진행한다. 자세한 조작은 [운영 기록 안내](OPERATIONS.md)에 있다.

**연결·전력**은 먼저 Demo에서 UI와 저장 흐름을 확인하고, 사내에서는 실제 필드의 제공 여부·권한·완전성·최신성·단위·식별 근거를 별도로 확인한다. 현재 Live 전송 어댑터는 미구현·미검증이며 켤 수 없다. 이 확인표를 채우거나 설정 파일을 바꾸는 것으로 활성화되지 않는다. 검증된 어댑터가 제공되는 버전인지 먼저 확인한다.

LLDP 최신 원천 관측도 물리 링크의 계속 정상·양방향 정상·내부 AP 매핑을 뜻하지 않는다. 전력은 측정 지점·지표·시각과 당시 귀속을 확인한다. 직접 AP 소비전력도 새 장비의 확인된 기간 전 표본을 새 세대에 붙이면 안 된다. [부가 관측 안내](ENRICHMENT.md)와 [자료 사전](DATA_DICTIONARY.md)을 함께 사용한다.

## 인수 시 남길 미확인 범위

- 사내 Windows 11·AD 정책, 관리자 권한·로그온 권한, 실제 서비스/예약 작업 계정과 재부팅·로그아웃·절전
