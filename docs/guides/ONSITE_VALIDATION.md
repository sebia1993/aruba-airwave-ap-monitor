# 사내 운영 확인 기록

개발 테스트·GitHub Windows CI와 실제 사내 PC/장비 확인을 구분한다. 아래 항목은 현장에서 확인하기 전까지 **미확인**이다. 계정 암호·쿠키·토큰·원문 사내 XML을 공개 저장소나 외부 서비스에 올리지 않는다.

| 항목 | 기록할 근거 | 현장 상태 |
|---|---|---|
| 패키지 식별 | ZIP SHA256, VERSION.json 소스/단계, Windows CI 링크 | 미확인 |
| PC 환경 | Windows 11 버전/아키텍처, 사용자/수집 계정 | 미확인 |
| 운영 방식 | 서비스 또는 예약 작업의 허용 여부·이름·실제 실행 경로 | 미확인 |
| 권한 | 선택 계정의 데이터 폴더 수정·서비스/배치 로그온 권한 | 미확인 |
| 데이터 분리 | 버전 폴더 밖 로컬 데이터 폴더, Demo/Live 별도 경로 | 미확인 |
| DPAPI | 실제 수집 계정으로 등록·재시작 복호화, 계정 변경 시 재등록 | 미확인 |
| 프록시·TLS | 같은 계정의 프록시/PAC 조건, 이름/체인/기간 검증 | 미확인 |
| AirWave | 로그인·AP 목록·분류·같은 필터의 대수 대조 | 미확인 |
| 수집 독립성 | 브라우저 종료 후 RunId 증가·마지막 유효/전체 확인 시각 | 미확인 |
| 인증 차단 | 거절 뒤 자동 로그인 중단 유지, 명시적 재시도/재등록 | 미확인 |
| 중복·포트 | 같은 데이터의 중복 시작 거부, 포트 충돌 시 안전한 실패 | 미확인 |
| 자동 시작 | 로그아웃·재부팅 후 선택 계정으로 재개, 회차/열린 사건 보존 | 미확인 |
| 절전 복귀 | 허용된 PC 절전 조건, 복귀 후 수집·공백·중첩 없음 | 미확인 |
| 비정상 종료 | 선택 방식의 실패 복구 정책, 중단 회차·누락 구간 표시 | 미확인 |
| 백업 | 일일 성공/검증, 최근 7개, 실패 시 이전 정상본 유지 | 미확인 |
| 업데이트 | 별도 사전 백업, 데이터/설정/이력 보존, 새 실행 경로 | 미확인 |
| 복원 | 별도 검증 환경에서 호환 검사·공백·재등록·이력 대조 | 미확인 |
| 등록 제거 | 해당 등록만 제거, DB·설정·자격 증명·백업 그대로 유지 | 미확인 |
| 장기 운영 | 실제 주기·AP 대수·메모리·DB 성장·오류/백업 상태 | 미확인 |
| 부가 관측 | 스위치/포트 식별·LLDP 출처/원천 시각·PoE 의미/단위 | 미확인; 검증 전 자동 활성화 금지 |

Windows Server 기반 CI의 서비스/작업 실행 성공은 사내 Windows 11의 재부팅·AD 정책·장비 검증을 대신하지 않는다. 실제 전원 차단 또는 디스크 고장 시험을 하지 않았다면 그 범위를 완료로 표시하지 않는다.
