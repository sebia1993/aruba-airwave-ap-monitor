# Windows 실행 안내

## EXE로 간단히 실행

ZIP 전체를 새 폴더에 풀고 최상위 **`AirWaveAPMonitor.exe`를 더블클릭**한다. Live, 기본 데이터 폴더, 포트 8765로 시작하고 기본 브라우저를 연다. 처음에는 설정 화면에서 서버와 계정을 등록한다. `app` 안의 EXE를 직접 찾아 실행할 필요가 없다.

수집기 창은 실행 중 열어 둔다. 브라우저 종료는 수집을 중지하지 않는다. 수집기 창에서 `Ctrl+C` 또는 창 닫기로 종료한다. 같은 데이터셋이 실행 중이면 최상위 EXE를 다시 실행하여 그 화면을 열 수 있다. 다른 프로그램·다른 데이터셋이 포트를 점유하면 재사용하지 않고 오류를 표시한다. 이전 v0.1.0 수집기는 종료 후 새 버전으로 실행한다.

사용자 지정 경로·포트는 바로가기 대상의 EXE 뒤에 인수를 추가하거나 패키지 루트 PowerShell에서 실행한다. 경로에 공백이 있으면 따옴표로 감싼다.

```powershell
.\AirWaveAPMonitor.exe --mode live --data-dir "D:\AirWave Data\live" --port 8765
# 가상 Demo를 별도 데이터로 실행:
.\AirWaveAPMonitor.exe --mode demo --port 8766
```

최상위 실행기가 데스크톱 모드를 지정한다. 일반 사용자는 추가 옵션이 필요 없다. `--no-browser true`는 자동 검사에서 브라우저와 오류 대화상자를 생략하는 고급 옵션이다. 이 경우 오류는 콘솔/종료 코드로 확인한다.

파일 누락 오류이면 ZIP 전체를 다시 새 폴더에 푼다. 권한 오류이면 기존 데이터 폴더 접근 권한과 실행 계정을 확인한다. 포트 충돌이면 기존 실행을 확인하고 정해진 운영 방식 하나만 사용한다. 데이터나 설정을 지워서 오류를 회피하지 않는다.

## 백엔드 직접 실행과 운영 도구

핵심 감시 패키지의 대화형 실행·서비스·예약 작업·계정·제거 절차는 [README_WINDOWS.md](README_WINDOWS.md)에 있다. 과거 초기 진단 전용 ZIP은 그 ZIP에 동봉된 초기 진단 안내를 따른다. 과거 진단 ZIP에 새 운영 기능이 들어 있다고 해석하지 않는다.
