# 사내 초기 연결 확인 기록

개발 단계의 자동 검사와 별도로 실제 운영 PC에서 작성한다. 아직 확인하지 않은 칸은 `미확인`으로 남긴다. 계정명·출처·원문 XML·비밀번호·쿠키·토큰·인증서·DB를 외부 제출할 필요가 없다. 이 문서에는 비밀을 기록하지 않는다.

| 항목 | 현장 기록 |
|---|---|
| 확인 시각, 패키지 버전·소스 커밋·ZIP SHA256 | 미확인 |
| Windows 버전·아키텍처 | 미확인 |
| 실제 프로세스 실행 계정 확인(외부 문서에는 이름 생략 가능) | 미확인 |
| 데이터 폴더 쓰기와 Live/Demo 분리 | 미확인 |
| 연결 경로: OS 기본 / 명시적 직접 / 명시적 고정 프록시 | 미확인 |
| 사내 PAC·프록시·인증서 조건을 담당자가 확인했는지 | 미확인 |
| TLS 결과와 HTTP 상태(응답 전 실패면 미수신) | 미확인 |
| 로그인·AP 목록 조회·파싱 단계별 결과 | 미확인 |
| 유효 AP·제외·중복·알 수 없는 상태의 건수 | 미확인 |
| AirWave 화면/기준 목록과 AP 대수·포함 범위 대조 | 미확인 |
| 실제 Up/Down 표본과 조회 결과 대조 | 미확인 |
| 앱 재시작 후 같은 실행 계정의 자격 증명 복호화 | 미확인 |
| 계정 재등록·명시적 인증 재시도 필요 여부 | 미확인 |
| 오류가 있을 때 안전한 오류 코드·단계(원문·비밀 제외) | 미확인 |

AP 목록이 조회되더라도 전체 대상 확인과 자동 감시 이력의 검증은 별개다. 이 초기 패키지에는 주기 수집·사건·SQLite·서비스·예약 작업 기능이 없다. 서비스 계정, 재부팅·절전 복귀, 장기 실행, 복구·백업 및 업데이트 절차는 후속 패키지에서 별도로 확인한다. LLDP·스위치 포트·PoE는 출처·시각·필드·단위를 확인하기 전 활성화하지 않는다.
